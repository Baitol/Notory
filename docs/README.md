## 🎯 Короткий огляд системи

Notory — це автономний (offline-first) інструмент для фіксації польових нотаток із прив'язкою до географічних координат та групування їх у звіти інспекцій:

```
┌─────────────────────────────────────────────────────────────┐
│                    ПРЕЗЕНТАЦІЙНИЙ ШАР (UI)                  │
│   HomeScreen  │  ReportDetailScreen  │  MapScreen  │ Picker │
└──────────────────────────────┬──────────────────────────────┘
                               │  Спостереження (ref.watch)
                               │  Виклик дій (ref.read / notifier)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                 ШАР СТАНУ (Riverpod Notifier)               │
│                     ReportsNotifier                         │
│             (кешує список ReportWithNotes)                  │
└──────────────────────────────┬──────────────────────────────┘
                               │  Виклики операцій збереження/читання
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                     СЕРВІСНИЙ ШАР (Service)                 │
│                     DatabaseService                         │
│      (бізнес-логіка, транзакції, об'єднання запитів)        │
└──────────────────────────────┬──────────────────────────────┘
                               │  Drift Query API
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                  ШАР ДОСТУПУ ДО ДАНИХ (DAO)                 │
│               AppDatabase (Drift SQLite API)                │
└──────────────────────────────┬──────────────────────────────┘
                               │  Файлові операції у фоновому ізоляті
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                  ФІЗИЧНЕ СХОВИЩЕ (Storage)                  │
│                     notory.sqlite                           │
└─────────────────────────────────────────────────────────────┘
```

Для вивчення деталей кожного конкретного компонента переходьте до відповідних файлів у цьому розділі.
